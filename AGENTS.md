# Repository instructions

## Supply and demand documentation

- Store all documentation about the Supply & Demand Trading strategy and its implementation inside `supply_and_demand/`.
- This includes requirements, design notes, trading rules, research, examples, testing reports, and supporting documentation assets.
- Update existing documents in that folder where appropriate; create new documents or subfolders there when needed.
- Example: place a market-structure design at `supply_and_demand/market-structure-design.md`.
- Apply this convention whenever working on supply and demand, including when a request does not repeat the folder name.
