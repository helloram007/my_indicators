# Repository guidance

This repository contains personal indicators. Keep strategy-specific work inside its own directory.

For any work in `piprunner/`, read these files before planning or editing:

1. `piprunner/AGENTS.md`
2. `piprunner/docs/PROJECT_CONTEXT.md`
3. `piprunner/docs/DECISIONS.md`
4. `piprunner/docs/roadmap.md`
5. Relevant sections of `piprunner/docs/requirements.md`

These files preserve the project handover across chats. Update them when decisions, implementation status or verification evidence change. Do not assume chat history will be available. Do not apply Piprunner trading rules to unrelated indicators.
