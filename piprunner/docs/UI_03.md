# Horizontal structure display 0.3

User request: replace cluttered bubble annotations with horizontal levels and current BOS/CHoCH labels carrying the timeframe. The supplied UI 0.2 screenshot is user-provided evidence of operation, but confirms presentation remains too cluttered. This update does not approve or replace the strategy's structural rules.

## What changes

Horizontal lines is now the default drawing style. The old origin/confirmation bubble history and stepped protection plot are hidden in this style. Two current confirmed 4H reference levels are drawn from their pivot origins to the right edge, with a single small text annotation per level: for example `4H LH 1.33386 · protected`. The label updates as the current reference changes; superseded live-level objects are removed. Actual prices are used without vertical offsets.

Protected references use a thicker line; consumed references use dotted lines. Only a finalized close consumes a level, not live price or a wick. A reference already beyond price when first confirmed is marked consumed without inventing a historical break event. Levels anchored on past pivot candles only become visible after confirmation.

At most three completed break segments appear by default, dashed from the broken pivot to the confirming close, with `4H BOS ↑`, `4H BOS ↓`, `4H CHoCH ↑`, `4H CHoCH ↓` or unclassified `4H Break`. These are distinct historical records, not a live label changing an old CHoCH into BOS. Their tooltips identify price, confirmation time, publication time and proposed classification status.

The checklist defaults to Summary. Compact and Full remain selectable. Legacy labels restores the previous drawing method. Current levels, confirmed break history, count (including zero), label offset, line width, protection and panel are separately configurable. Minimal hides historical break events; Off hides educational drawings. Clearer line geometry reduces clutter but no automatic text collision detection is claimed.

## Proposed 4H break definitions

This is a proposed educational overlay, not the approved 15m entry CHoCH/swing-break definition. It reads the PREVIOUS structural state and reference before newly confirming pivots are added:

- A finalized 4H close crossing strictly above the latest already confirmed high is bullish BOS if prior bias was bullish, bullish CHoCH if prior bias was bearish, otherwise an unclassified upward Break.
- A finalized 4H close crossing strictly below the latest already confirmed low is bearish BOS if prior bias was bearish, bearish CHoCH if prior bias was bullish, otherwise an unclassified downward Break.
- Prior close must be on the other side or equal. Each pivot identity can generate only one break. Equality, wick-only breaches and already-broken references do not generate events.
- Classification uses prior bias, so same-close bearish invalidation can display bullish CHoCH while the bias engine becomes NEUTRAL. CHoCH does not automatically mean bullish bias. The existing HH/HL and protection/rearm rules remain unchanged.

Every displayed timeframe prefix is **4H**, even on a 1H or 15m chart. Independent 1H and 15m structural engines remain unimplemented. Do not claim these labels validate the End-of-P2 entry sequence.
