# Learning display update 0.2

Changes prompted by chart review 001. Structural model remains proposed B4H v0, unchanged. No setup or order logic added.

## Apply the update

Replace the whole Pine Editor source with the current `src/piprunner_4h_bias.pine`, save and update the chart. Confirm the indicator title ends with **UI 0.2**. Existing TradingView input settings may persist; choose the settings below explicitly when comparing.

Recommended initial review: Training, Compact checklist, future rows off, panel transparency 0, label spacing 0.5 and structure colors on. Move the panel to another corner if it covers price. The display cannot reserve empty chart space automatically.

## New controls

- Checklist layout: Compact shows current 4H evidence and a summary that later modules are undefined. Full also includes feed details, pivot origin timestamps and history counts.
- Expand future module checklist: Training-only switch restores the detailed waiting/undefined rows. Future modules remain inactive regardless of visibility.
- Developing-candle explanation: displays the close-only invalidation rule and, in Training/Guided, scheduled current 4H closing time in UTC. “Price beyond level; WAIT for 4H close” compares current chart price with the confirmed protection, for explanation only. It does not change bias or predict the final close. In historical review it describes the selected endpoint, not a reconstructed intrabar path.
- Label spacing: offsets drawings by a fraction of the closed confirmation candle's 4H high-low range, with a ten-tick minimum range. Three deterministic vertical lanes separate adjacent publication events; state labels sit above confirmation labels on the same event. Zero restores price-level placement. This reduces overlap but is not a collision-detection algorithm.
- Structure colors: HH/HL bullish color, LH/LL bearish color, initial/equal pivots neutral. Switch off to restore high-side/low-side coloring. These colors describe pivot relationships, not full bias approval.
- Panel transparency: 0 is fully opaque, the new default. Larger numbers reveal more chart behind the panel.

Origin timestamps remain on actual pivot candles. Spaced label prices are display coordinates; the label text and tooltip show the actual pivot price. Confirmation/state explanations are in hover tooltips, with shorter on-chart text. Labels use only confirmed prices for placement, never a moving live range or future repositioning.
